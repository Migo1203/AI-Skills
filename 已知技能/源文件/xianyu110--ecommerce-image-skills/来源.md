## 用途与依赖

该技能适合参考其“产品身份锁定→详情页分屏→每屏提示词→素材拼接切片”的流程。准确策划需要真实产品参考图、已确认卖点和目标平台；只输出文字规划及提示词不需要生图账号。

`multi-angle-set` 则以产品参考图为基础，逐张规划正面、侧面、背面、45°、俯视等角度，重复身份与光线约束，再用可用的参考图生图工具输出。它是提示词和工作流，不是三维重建工具，不能保证机身或不可见细节完全真实。可先人工读取技能并使用当前可用的图片工具；这不等于已安装或自动加载该技能。中文说明和音箱练习见[使用说明](../../../学习资料/Multi-Angle-Set使用说明.md)。

- 运行长图拼接或多图网格脚本需要 Python 3 和 Pillow；网格脚本使用 `ImageOps.fit`，可能裁剪图片边缘，不能默认保证产品完整留白。
- 运行可选生成脚本还需要可用的图像 API、`GPTIMAGE_API_KEY` 及对应服务访问；脚本使用 Python 标准库，可选 `GPTIMAGE_BASE_URL`。本次未检查或配置任何密钥。
- 上游列出的模型名、第三方 API 与在线站点原样保留用于来源追溯，不代表已验证其真实性、可用性或服务质量，也不是实际使用这些站点的授权。
