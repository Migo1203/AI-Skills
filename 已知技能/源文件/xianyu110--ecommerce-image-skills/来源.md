## 用途与依赖

该技能适合参考其“产品身份锁定→详情页分屏→每屏提示词→素材拼接切片”的流程。准确策划需要真实产品参考图、已确认卖点和目标平台；只输出文字规划及提示词不需要生图账号。

- 运行拼接脚本需要 Python 3 和 Pillow。
- 运行可选生成脚本还需要可用的图像 API、`GPTIMAGE_API_KEY` 及对应服务访问；脚本使用 Python 标准库，可选 `GPTIMAGE_BASE_URL`。本次未检查或配置任何密钥。
- 上游列出的模型名、第三方 API 与在线站点原样保留用于来源追溯，不代表已验证其真实性、可用性或服务质量，也不是实际使用这些站点的授权。

入口中的750像素宽、1546像素切片高度、京东移动端/PC尺寸等是上游提供的配置或经验，不能视为淘宝、天猫、京东等平台的官方当前规则。实际投放或上传前，应按目标平台、类目和端口核验官方最新要求。

源文件保存不等于安装、自动加载或具备生图能力。当前用户的协作分工仍是AI分析资料、提供视觉策略/文案/提示词，用户自行生成素材并在PS排版；归档这些上游脚本不会改变该分工，也没有执行脚本或上传产品图片。
