# 电商布局参考库

用于单图构图选择、详情页模块编排和布局比较。先明确图片用途、主信息、产品形态、现有素材与文案长度，再选择适合的区域关系。这里的线框是可调整的示意，不是固定比例、平台尺寸或自动套版；不要求一套图用遍所有布局。

查找：图文分区｜卖点分组｜整体与特写｜摄影留白｜主次拼图｜多视窗｜整页节奏｜PS交接。

## 如何选择

- 从用户要理解的问题选结构：识别商品、理解一项利益、查看真实细节、代入使用、比较选项，各有不同信息任务。首图先能认出商品，不让氛围或文字遮蔽产品。
- 先检查素材是否支持：产品朝向、裁切余量、留白、有效分辨率和可用细节图。多格不能弥补素材缺失，同一照片放大也不会增加真实细节。
- 单图优先推荐一种布局，说明它为什么适合当前事实和素材；只有另一种能形成实质取舍时才给备选。保留已采用构图，局部改字或移动元素无需重选布局。
- 平台上架主图、附图、详情模块和概念海报分别判断。先核验当前位置能否使用文字、场景、面板及其他元素；无新增文字方案也可用主体、裁切和留白组织画面。
- 整套锁定已有品牌色角色、标题/说明层级、图标语言及对齐习惯；构图、视角、画面密度随各图任务变化。配色和字体以品牌、可读性为依据，不因产品有颜色就禁用中性色。

## 六类布局

### 1. 图文分区：让产品和一个解释各有位置

```text
[ 产品主体 / 使用画面 ][ 标题     ]
[                    ][ 简短解释 ]
[ 必要条件或说明，按关联位置放置  ]
```

- **适用**：产品识别、一个核心利益或参数解释。横向产品也可上下分区，不固定左图右文。
- **素材前提**：完整或足以识别的产品图，朝向和视线允许另一侧放文字。
- **安排**：产品区与文字区形成一个主次关系；文字沿同一基准线组织。背景已有自然留白时先利用留白，面板只是对比不足时的可选办法。
- **PS衔接**：先建立产品和文字组，再按真实轮廓调整间距；面板不能侵入关键接口、包装或阴影。
- **换布局的信号**：产品被压得过小、说明过长或两区同等抢眼。先删减文字或拆成模块，不靠缩字解决。

### 2. 卖点分组：把有关联的信息放在产品附近

```text
[ 产品 / 使用动作 ][ 核心信息 ]
[                 ][ 补充依据 ]
[                 ][ 适用条件 ]
```

- **适用**：同一主题下的少量功能、使用步骤或参数说明；存在主次时不要做等权卡片。
- **素材前提**：每项有依据，且对应关系能说清；图标不是必需素材。
- **安排**：主信息先读，相关标签与说明靠近；独立购买理由过多时拆图。步骤必须来自真实操作顺序。
- **PS衔接**：先定一条对齐线，再统一同类文字/图标样式；只对需要图形辅助的信息使用图标。
- **换布局的信号**：模块重复说同一句话、每条都要长段解释，或读者无法把说明对应到产品。

### 3. 整体与特写：让局部证据回到真实部位

```text
[ 产品整体          ][ 局部图 ]
[                   ][ 短说明 ]
[ 与产品同一位置对应的第二处细节 ]
```

- **适用**：接口、表面、连接部位、可见结构或工艺细节。
- **素材前提**：同一SKU的清晰实拍或可验证设计资料；特写不能来自其他型号，不能用AI生成纹理证明材质或性能。
- **安排**：保留整体识别，特写只展示本图任务所需部位；圆形、矩形和裁切框按内容选，不固定放大镜形状。
- **PS衔接**：从真实素材裁取，用蒙版和简洁标注建立位置对应；放大倍率不得使画面像素不足或误导尺寸。
- **换布局的信号**：没有可靠细节素材、特写遮住整体、标注线混乱。回到整体图和已知描述，不补造细节。

### 4. 摄影留白：用场景关系表达一个主题

```text
[ 可读的自然留白 / 短标题 ]
[            产品主体     ]
[ 场景与承托面，控制干扰   ]
```

- **适用**：生活方式、情绪价值、品牌氛围、概念海报和详情首屏；需符合具体展示位置规则。
- **素材前提**：产品能与场景的透视、光线、尺度协调，或有可合成的产品图和背景。
- **安排**：让产品成为视觉重点，留白避开复杂纹理；不固定三分之一位置、主体占比或光线风格。场景不能暗示未经确认的防水、耐热等能力。
- **PS衔接**：沿用已选底图，通过裁切、局部明暗和文字位置解决可读性；缺素材时再按本技能提供背景或含产品概念图提示词。
- **换布局的信号**：场景比商品更抢眼，文字必须压住关键部位才能放下，或场景不符合商品事实。

### 5. 主次拼图：让一个主要画面带动补充信息

```text
[     主要画面     ][ 补充图 ]
[                  ][ 补充图 ]
[ 各区域按内容安排短标签或说明 ]
```

- **适用**：一个核心利益配必要细节、系列概览或多个有关联的使用情境。
- **素材前提**：各格确有不同信息，且色温、商品身份和拍摄尺度能够协调。
- **安排**：按内容决定格数和主次，不强制三格或主格占一半；保持共同边距和沟槽。不要把完整详情页压成一张小拼图。
- **PS衔接**：按共同网格建立蒙版，先放产品关键区域再裁切；缩小后检查每格是否仍有意义。
- **换布局的信号**：小格看不清、素材相似导致重复、裁切丢失产品身份。减少格数或拆成连续模块。

### 6. 多视窗：清楚比较不同场景、选项或视角

```text
[ 场景 / 选项甲 ][ 场景 / 选项乙 ]
[ 对应短标签    ][ 对应短标签    ]
[ 共用说明或真实选择条件          ]
```

- **适用**：规格选择、使用场景、产品不同视角；差异本身就是本图重点。
- **素材前提**：有可对比的真实内容；选项与SKU一致，尺寸/性能对比有一致口径。
- **安排**：为可比信息使用一致的裁切和标签位置，标签明确对应；要重点推荐某项时给出理由并改变视觉主次。
- **PS衔接**：统一窗口、文字基线和必要的尺度参照；不能靠任意缩放制造大小或性能差异。
- **换布局的信号**：内容不可比、每窗文字过长，或必须用多处注释才能解释差异。改用逐模块说明或有依据的规格表。

## 仅在材料支持时增加的结构

- **步骤序列**：按产品实际使用顺序分帧；步骤数来自操作，不为凑版式编步骤。短流程可接卖点分组，多步骤优先分模块。
- **结构解析**：只有真实内部结构图、工程资料或对应实拍支持时才规划拆解图；资料不足改用可见细节，不能凭外观生成内部结构作为商品事实。
- **规格/对比表**：需要准确字段、单位和比较条件时用表格承载，不挤进营销画面；未知信息保留在稿外缺口清单。

## 整页编排：按决策顺序连接模块

先写出读者要解决的问题，再为各模块选布局。可从“是什么 → 对我有什么用 → 依据是什么 → 是否适合我 → 如何选择”删减和调整，不要求每个商品走齐全部阶段，也不把这套顺序称作平台规定。

| 页面决定 | 执行动作 |
| --- | --- |
| 首屏承接 | 对应用户实际进入页面的商品、SKU和主信息，先识别商品，再给有依据的购买理由 |
| 模块分工 | 每屏一个主要问题；标题承接前屏留下的问题，不重复堆同一卖点 |
| 网格与重复 | 按当前画布建立共同内容边界、对齐线、标题层级和间距角色；需要时给可调整的起始值 |
| 节奏与变化 | 依据任务交替使用整体、近景、信息模块和必要留白；不是为变化而轮流套模板 |
| 条件与证明 | 参数的单位/条件紧邻对应内容，证据与宣称可对应，重要限制不能只藏在页尾 |
| 移动端 | 按实际展示宽度缩小检查；小格不可辨、横排文字过密时改为纵排或拆屏，不仅做等比缩小 |
| 平台模块 | Amazon A+等先确认可用模块、资格及官方尺寸，再规划桌面和移动端区域；不预设统一尺寸或手机9:16 |

例如，用户确认的桌面收纳架，资料仅支持可调层高，已有整体图、调节细节图和桌面场景图：可用整体识别 → 分区说明“按物品调整层高” → 整体与真实特写说明调节部位 → 有尺寸资料时再做适配模块。没有承重数据就不做承重证明；没有内部结构图就不做爆炸图。此例只演示模块分工，不代表已有真实商品或效果验证。

## 输出布局建议并衔接PS

按任务选用以下信息，不强制全部输出：

1. **任务与推荐布局**：本图要回答的问题、选择理由；已有采用构图时说明如何沿用。
2. **区域关系**：产品、标题、正文、细节、条件分别如何组织；用简短文字或粗线框说明。用户明确要布局参考、需要比较方案或关系较复杂时给线框。
3. **素材与一致性**：各区用哪张素材、现有素材够不够；本套沿用的品牌色角色、字体层级、标注/图标规则。
4. **计划参数**：需要具体数值时按本次画幅给计划边距、区域和文字层级；没有实际图时不称作实测。
5. **落地与验收**：用户提供采用图后核对裁切/缩放，再给X/Y/W/H和图层动作；检查产品识别、可读性、事实、对应关系和小图预览。

多张连续方案可在开头用简短“系列样式约定”记录共用色彩、文字层级、边距与图标规则，单张只写差异；供用户复制到新工具的每条最终提示词仍须自包含。只改文案时不要额外交付布局库、全页规划或生图步骤。
