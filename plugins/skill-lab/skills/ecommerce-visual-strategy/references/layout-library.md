# 16类电商布局参考

这些是重新编写的通用构图方法。覆盖用户看重的16类表现方向，不沿用上游数据库原文和固定参数。线框表示空间关系，大小、左右和窗口数量按当前素材调整。构图方式不能证明性能；上架主图允许什么须单独核验，不能把以下带文字的附图布局直接套给主图。


完整制作按[可编辑制作流程](editable-production.md)将文字、图形和标注保留为独立SVG对象。以下PS动作描述分组、裁切、蒙版和对齐原则；先用于AI制作，用户选择PS后再给具体操作。

原个人库6类合并到本库，不额外重复计数：图文分区→01，卖点分组→02，整体与特写→05，摄影留白→10，主次拼图→12，多视窗→16；等口径选项比较也可用11。保留原六类的区域线框与整页组织方法。

## 01 图文分区

```text
[ 产品主体 / 使用画面 ][ 标题     ]
[                    ][ 简短解释 ]
[ 必要条件或说明，按关联位置放置  ]
```

- **用途**：完整识别商品，同时解释一个利益或参数；可上下分区。
- **素材**：可识别的完整产品图，有合理留白或可合成背景。
- **组织**：先产品或主信息，再说明；文字共用基准线。背景足够干净时不用面板，复杂时用有理由的遮罩/面板改善对比。
- **PS**：产品、标题、正文分组；按轮廓调整文字边界，检查包装和阴影不被切断。
- **失效**：产品过小或解释过长时删减、拆图，不靠缩字硬塞。

## 02 卖点分组

```text
[ 产品 / 使用动作 ][ 核心信息 ]
[                 ][ 补充依据 ]
[                 ][ 适用条件 ]
```

- **用途**：同一主题下的功能、参数或少量步骤。
- **素材**：每项有依据，标签能对应产品部位或操作。
- **组织**：组内靠近，组间拉开；主项优先，图标可省略。多个独立购买理由优先拆图。
- **PS**：复用文字层级、图标笔画和对齐线；先放最长标签检查容纳能力。
- **失效**：所有模块同等抢眼或重复一句话时重分主次，不机械凑三块。

## 03 主体与短标题

`[短标题 / 大幅商品或单一场景 / 必要条件]`

- **用途**：快速识别、一个明确主题或简洁首屏。
- **素材**：有足够辨识度的主体及可读留白。
- **组织**：主体与短标题形成清楚层级；标题不遮挡关键形态。需要文字表达商品身份时先说清品类。
- **PS**：先确定主体裁切，再试排标题和短说明；用移动端小图查看产品是否仍可认出。
- **失效**：只剩氛围、巨字压住商品或条件无处安放时转01或拆模块。

## 04 形态呼应

`[沿产品轮廓/运动方向组织的图形与文字]`

- **用途**：产品造型或已有品牌图形能支持明确的创意方向。
- **素材**：真实轮廓、授权图形，或有证据的工作机制资料。
- **组织**：从弧线、切面、重复节奏等组织视线；装饰轨迹不冒充气流、声学或防护效果。
- **PS**：产品保持原样，衍生曲线/图形独立成层，可调透明度和遮挡关系；长文字仍用可读基线。
- **失效**：创意比商品更抢眼、形态被改造或读者可能把装饰当性能时简化。

## 05 整体与特写

```text
[ 产品整体          ][ 局部图 ]
[                   ][ 短说明 ]
[ 与产品同一位置对应的第二处细节 ]
```

- **用途**：接口、连接部位、可见表面和真实工艺细节。
- **素材**：同SKU清晰照片或可验证设计资料；单张低清图片放大不能增加细节。
- **组织**：整体可识别，窗口与部位能对应；圆窗、矩形或直接裁切按形状决定。
- **PS**：用真实照片、蒙版和必要引线制作特写，检查像素和尺度感。
- **失效**：无细节素材就列缺口，不生成虚假纹理、材质或接口填窗。

## 06 有依据的结构解析

`[真实结构层次 / 编号 / 对应解释]`

- **用途**：解释确有资料支持的内部层次、部件关系或装配。
- **素材**：结构图、工程资料或对应拆解实拍；仅外观照不够。
- **组织**：层次和方向符合真实结构，编号与说明对应；必要时注明示意及适用型号。
- **PS**：按已核实部件制作分层、引线和标签；透视统一，不能为了悬浮效果新增层数。
- **失效**：缺结构资料时转05可见细节；不能凭模型生成内部结构作为证据。

## 07 俯拍搭配

`[真实商品居主位 / 配件与道具围绕 / 短标签]`

- **用途**：到手组合、桌面/出行场景、物品关系。
- **素材**：可用俯拍素材，商品与道具尺度和光线可匹配。
- **组织**：主体主导，销售配件与装饰道具明确区分；摆位服务使用关系。
- **PS**：俯拍透视匹配后处理接触阴影、间距和裁切；到手清单与SKU核对。
- **失效**：道具被误认赠品或相机视角无法协调时减少道具、改用真实场景。

## 08 场景与悬浮信息

`[生活场景＋前景商品 / 避让主体的信息卡]`

- **用途**：需要保留场景氛围，同时解释一项信息。
- **素材**：实际场景或可合成的产品、背景；卡片区域有足够低干扰空间。
- **组织**：卡片是阅读辅助，透明度按对比决定，不强制毛玻璃；重要条件可读且靠近宣称。
- **PS**：场景和信息卡分层，必要时局部压暗/提亮；文字不随背景一起模糊。
- **失效**：卡片挡住关键部位或透明背景让文字难读时改实底或01分区。

## 09 斜向切片

`[场景甲 /斜分隔/ 场景乙 /斜分隔/ 细节]`

- **用途**：有关联的多场景、动作或特征，希望形成方向感。
- **素材**：确有不同信息、可裁切的图像，真实产品身份一致。
- **组织**：切片边缘不能切断关键部位；标签对应各片，斜线服务动线而非增加噪声。
- **PS**：用矢量蒙版控制切面，先验证最窄窗口；文本可保持水平以提高可读性。
- **失效**：小图难辨、文字交叉或过多切片时减少窗口，移动端改纵排。

## 10 摄影留白

```text
[ 可读的自然留白 / 短标题 ]
[            产品主体     ]
[ 场景与承托面，控制干扰   ]
```

- **用途**：产品质感、品牌氛围、详情首屏或概念海报。
- **素材**：主体与空间的透视、光线、尺度可信。
- **组织**：以场景关系而非装饰解释主题；主体位置、景深和占比根据轮廓决定，不固定三分之一。
- **PS**：沿用实际底图，优先裁切、避让和局部明暗；保持商品标识和必要条件清晰。
- **失效**：只看出场景看不出商品、背景暗示无证性能或文字没地方放时换布局。

## 11 等权卡片

`[选项甲＋标签][选项乙＋标签][选项丙＋标签]`

- **用途**：同层级选项、步骤快览或同口径对比。
- **素材**：真实可比内容，SKU、单位和裁切尺度可统一。
- **组织**：卡片保持共同边界和文字基线；有主推荐就别伪装成等权，需说明推荐依据。
- **PS**：统一窗口和标签样式，先检查最长文字及最小图像；窄屏优先重排。
- **失效**：数据不可比、卡片重复或每项长段说明时用规格表或分屏。

## 12 主次拼图

```text
[     主要画面     ][ 补充图 ]
[                  ][ 补充图 ]
[ 各区域按内容安排短标签或说明 ]
```

- **用途**：一个主利益需要不同细节、场景补充。
- **素材**：各窗口有信息增量，产品与色温可协调。
- **组织**：主区域先读，补充窗口支持主问题；格数、比例和沟槽按内容，不固定三格或50%。
- **PS**：共用网格与蒙版，按产品关键部位裁切；不能把完整长页面压成一图。
- **失效**：小格无意义或没有不同素材时减少格数，不重复同一照片凑数。

## 13 中心与周边信息

`[上方解释 / 左信息 ← 产品 → 右信息 / 下方解释]`

- **用途**：说明一个核心产品的部位、能力或关联关系。
- **素材**：每个信息有依据且可对应中心主体；细长产品未必适合围绕布局。
- **组织**：阅读顺序有起点，引线只为消除歧义；四周不是必须填满四条。
- **PS**：先留主体安全轮廓，再放说明及可选引线，防止交叉和拥挤。
- **失效**：信息过多、方向难辨或手机字太小时转02分组、分图。

## 14 场景全景

`[宽幅环境 / 明确的产品落点 / 少量信息]`

- **用途**：环境尺度、品牌情绪或真实使用背景需要完整呈现。
- **素材**：场景合理、主体辨识足够，产品位置与尺度可信。
- **组织**：景深和镜头按任务选择；关键部件、说明不可因电影感失焦。
- **PS**：依据容器设置裁切安全区，手机需另查模块行为；保留产品识别与必要条件。
- **失效**：环境吞没商品、裁切后失去意义或把不支持的环境适用性暗示成事实时重构。

## 15 流程序列

`[真实步骤1] → [真实步骤2] → [真实结果/下一步]`

- **用途**：使用、安装、清洁或已有材料支持的过程叙事。
- **素材**：真实操作说明及可用步骤图；品牌发展历程需可核实记录。
- **组织**：一步一个动作，方向明确；不是所有过程都要三步，不虚构效果演进。
- **PS**：统一帧、编号和动作标签；步骤长时拆模块，手机改顺序纵排。
- **失效**：步骤有安全缺口、资料不完整或用时间线暗示未经证明的效果时先补证。

## 16 多视窗

```text
[ 场景 / 选项甲 ][ 场景 / 选项乙 ]
[ 对应短标签    ][ 对应短标签    ]
[ 共用说明或真实选择条件          ]
```

- **用途**：同时理解使用情境、局部和不同视角之间的关系。
- **素材**：同一SKU的多张有效图片，不同窗口各有职责。
- **组织**：可有主次，不要求等大；窗口标签清楚，不能把不同变体拼成实际不存在的套装。
- **PS**：统一窗口语言和色温，必要时标注不同视角；保留真实比例线索。
- **失效**：素材不足、标签难对应或重复信息时简化为05或一张场景图。

## 从布局到交付

每张建议按需包含：本图问题→推荐编号与理由→粗线框/区域关系→使用素材→系列样式→文字层→提示词或PS动作→验收。粗线框不是像素实测。

尚无采用图时给计划值；采用图确定后检查尺寸、裁切、产品轮廓再给X/Y/W/H、字号和间距。连续页面先排模块职责，再选各屏布局；移动端根据实际容器重排，不仅等比缩小。通用整页组织见下文；Amazon A+任务另读[A+页面](amazon/a-plus.md)。

## 仅在材料支持时增加的结构

- **步骤序列**：按产品实际使用顺序分帧；步骤数来自操作，不为凑版式编步骤。短流程可接卖点分组，多步骤优先分模块。
- **结构解析**：只有真实内部结构图、工程资料或对应实拍支持时才规划拆解图；资料不足改用可见细节，不能凭外观生成内部结构作为商品事实。
- **规格/对比表**：需要准确字段、单位和比较条件时用表格承载，不挤进营销画面；未知信息保留在稿外缺口清单。

## 整页编排：按决策顺序连接模块

先写出读者要解决的问题，再为各模块选布局。可从“是什么 → 对我有什么用 → 依据是什么 → 是否适合我 → 如何选择”删减和调整，不要求每个商品走齐全部阶段，也不把这套顺序称作平台规定。

| 页面决定 | 执行动作 |
| --- | --- |
| 首屏承接 | 对应用户实际进入页面的商品、SKU和主信息，先识别商品，再给有依据的购买理由 |
| 模块分工 | 每屏一个主要问题；标题承接前屏留下的问题，不重复堆同一卖点 |
| 网格与重复 | 按当前画布建立共同内容边界、对齐线、标题层级和间距角色；需要时给可调整的起始值 |
| 节奏与变化 | 依据任务交替使用整体、近景、信息模块和必要留白；不是为变化而轮流套模板 |
| 条件与证明 | 参数的单位/条件紧邻对应内容，证据与宣称可对应，重要限制不能只藏在页尾 |
| 移动端 | 按实际展示宽度缩小检查；小格不可辨、横排文字过密时改为纵排或拆屏，不仅做等比缩小 |
| 平台模块 | Amazon A+等先确认可用模块、资格及官方尺寸，再规划桌面和移动端区域；不预设统一尺寸或手机9:16 |

例如，用户确认的桌面收纳架，资料仅支持可调层高，已有整体图、调节细节图和桌面场景图：可用整体识别 → 分区说明“按物品调整层高” → 整体与真实特写说明调节部位 → 有尺寸资料时再做适配模块。没有承重数据就不做承重证明；没有内部结构图就不做爆炸图。此例只演示模块分工，不代表已有真实商品或效果验证。

## 输出布局建议并衔接SVG与PS

按任务选用以下信息，不强制全部输出：

1. **任务与推荐布局**：本图要回答的问题、选择理由；已有采用构图时说明如何沿用。
2. **区域关系**：产品、标题、正文、细节、条件分别如何组织；用简短文字或粗线框说明。用户明确要布局参考、需要比较方案或关系较复杂时给线框。
3. **素材与一致性**：各区用哪张素材、现有素材够不够；本套沿用的品牌色角色、字体层级、标注/图标规则。
4. **计划参数**：需要具体数值时按本次画幅给计划边距、区域和文字层级；没有实际图时不称作实测。
5. **落地与验收**：实际素材或用户采用图确定后核对裁切/缩放，再给X/Y/W/H和图层动作；检查产品识别、可读性、事实、对应关系和小图预览。

多张连续方案可在开头用简短“系列样式约定”记录共用色彩、文字层级、边距与图标规则，单张只写差异；供用户复制到新工具的每条最终提示词仍须自包含。只改文案时不要额外交付布局库、全页规划或生图步骤。
