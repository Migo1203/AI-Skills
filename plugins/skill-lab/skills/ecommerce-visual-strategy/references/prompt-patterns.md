# 背景与概念图提示词

这些是文字提示词的组织方法，不是工具调用或自动生图指令。使用用户选择的图像工具；只在明确指定工具且语法已知时添加专用参数。

## 先决定素材职责

- **后期合成的纯背景**：用户将真实产品素材放进PS。提示词不生成产品或替代产品的物体，保留承托与文案区域。
- **含产品的概念构图**：用户希望看产品在场景中的关系。提示词应使用参照和产品身份约束；概念效果不能替代产品真实性检查。
- **已有合格底图**：直接进入布局或PS指导，不要求重生成。

纯背景并不一定没有道具。允许的道具由场景和画面职责决定，但不得占用产品合成区、遮挡文案，或暗示没有依据的产品性能。

## 背景底图的组织顺序

1. **用途与画幅**：海报/详情模块/其他用途，比例与目标尺寸按本次任务填写。
2. **场景与承托面**：场景位置、真实空间关系、台面或地面材质、必要道具与景深。
3. **相机与透视**：观察高度、俯仰与朝向、承托面的透视；与用户产品素材的视角匹配。
4. **光线**：主光方向、软硬、环境色与接触阴影条件，便于后续合成。
5. **构图分区**：产品合成区、主副文案区、视觉动线与留白；使用本图目标决定位置，不套固定百分比。
6. **色彩与材质**：按品牌和当前系列说明，保证文字区域的对比与背景复杂度适合排版。
7. **避免项**：不出现本产品、产品代用品、文字、Logo、水印，以及本次事实限制不支持的场景暗示。

布局已确定时，把与本次生成任务有关的区域关系写入提示词：纯背景只写承托面、产品合成区和文字留白，不让模型生成产品/图文面板；含产品概念图才写真实产品摆位。特写、窗口和最终文字层由真实素材及PS承担，不能让模型填补证据缺口。

交付时把已知要求写成一段可复制提示词，再单列必要避免项。缺失的产品事实、尚未选择的画幅等放在提示词外说明；不能为了写满提示词而编造。若目标工具不支持独立负向提示词，将避免项写入主提示词。

## 含产品概念图的组织顺序

先说明附件用途与顺序，再描述图像：

- 产品参照：哪些图用于外观、结构、颜色、比例、文字和Logo。
- 风格参照：哪些图仅用于光影、色彩或氛围，不能借用其中另一款产品。
- 必须保持：来自实际参照的识别特征和已确认的功能/配件边界。
- 可以变化：场景、道具、相机位置和光线中获准调整的部分。
- 构图目标：产品与承托面的尺度关系、重点、留白及后续排版区域。
- 文字处理：主副文案另行交付，在PS中制作；概念图不要求生成最终排版文字。
- 检查要求：生成后复核产品结构、文字/Logo、透视、尺度和光影，不能声称提示词保证完全一致。

用户明确要求含产品时，不因“文字后排”而删除产品。仅有产品资料、没有可读参考图时，说明外观约束仍不足，给可执行的概念方向或纯背景选择，不编造已看见的细节。

每条最终提示词应能连同指定参考图单独交接：重述本图采用的布局关系、光线、色彩与保真要求，不只写“同上一张”。共用系列约定用于减少讨论重复，不能替代独立可复制的提示词。

## 用户选图后的衔接

根据实际采用图反馈，只调整有问题的构图、光影或素材需求。能用PS完成的裁切、避让、文字与局部合成，直接给PS操作建议。实际使用的提示词若与建议不同，分别记录，不把建议冒充执行记录。
