# 创意比较、实验方案与真实数据

## 先区分任务

- 没有数据：提出可检验假设与A/B版本。布局的适配性、可读性可以审稿，转化优劣尚不能确定。
- 有真实实验：核对分流、单位、样本与停止条件后分析。
- 前后换图、同时换价/广告、不同渠道流量：先做描述性比较，解释混杂，不能称为因果A/B结果。

先验证用户实际账号/产品是否能运行所需平台实验。技能不连接Amazon、不启动实验，也不声称任何槽位都支持随机分流。可使用真实后台实验报告；若平台只有模型化指标、订单/会话统计或聚类分流，不能伪造成此处脚本要求的独立用户二项数据。

## 方案与素材

复制[实验计划表单](../assets/experiment-plan.template.json)，记录experiment_id、SKU、市场、具体假设、主要变化变量、A/B描述、主要指标的事件与分母、收益方向、最小实际效应、分流比例、每组目标样本与确定依据。记录价格、库存、广告、流量渠道、其他创意、移动端裁切等控制项和可能混杂；它们在可读实验简报中展开。

优先一次比较一个主要变化，例如图内标题的表达或一张附图的信息组织。多项同时变化可以测整个方案包，但结果不能归因于其中单一布局。保持商品事实、配件与承诺不变。实际图片制作、语言和平台审阅完成后才进入实验；不要只比较Prompt就称测试成图。

运行前确定主要指标、固定样本停止条件、周期覆盖、最小实际效应和退款/利润等护栏。样本量取决于基线、希望识别的效应、显著性与功效；脚本不计算功效，不默认“7天/1000人足够”。不能看见有利结果就提前停，或测试很多指标后只挑赢家。没有稳定分流能力时保留为实验计划。

## 脚本支持的窄范围

```text
python scripts/analyze_experiment.py plan.json
python scripts/analyze_experiment.py plan.json --data observed-data.json
```

无数据只校验方案并返回`plan_only`。脚本只接受一个预先指定的二项主要指标、A/B两组、每个独立随机用户最多一次事件（unique_user_binary）、固定样本设计。事件数≤用户数。点击率只有在独立用户层去重、事件定义相符时才可用；展示次数、重复会话、订单件数、金额和平均客单价不是这种输入。

数据字段：schema_version、experiment_id、sku、market、source、data_kind（observed/synthetic）、metric、unit、window（start/end日期）、arms（A/B各n与events）、checks。`checks`明确记录deduplicated、concurrent、instrumentation_stable、no_known_confounders、fixed_horizon_reached。

输出率、B−A绝对差（0.01为1个百分点）、相对提升（A为0时null）、Wilson单组95%区间、Newcombe方法10的独立比例差95%区间，以及按计划分流比例的样本比例异常检查。SRM使用1自由度卡方近似、阈值0.001；此为工具诊断约定，不是Amazon规则。

仅当声明为真实数据、预登记同期随机分流、达到每组计划样本和停止条件、各质量条件为真、无SRM异常且事件/非事件均≥10时允许推断。稀疏数据仍显示数值供描述，但不推断；改用合适精确方法或专业分析。字段声明不等于工具已核实原始日志。

只有差值区间完整越过预设的最小实际效应时，才输出支持A或B的主要指标结论；跨零或未达到实际效应要求为inconclusive。不可据此自动上线：仍需护栏、利润、季节性和其他站点适用性判断。synthetic永远只演示；observational、未达样本和质量条件不满足时为descriptive_only。数据格式合法的描述分析退出码仍为0，调用方必须看`inference_allowed`和`decision`。

## 结果沉淀

保存计划版本、原始导出及来源、分析输入/输出、实际A/B素材、日期与复盘。给出“观察→不确定性→适用范围→下一步”；证据不足就保留原方案或继续按预设设计采样，不把失败/不显著结果丢弃。胜出只对本次人群、SKU、站点和指标成立，不能升级为布局库的普遍定律。

方法出处供核对（不是平台政策）：Wilson, 1927, DOI `10.1080/01621459.1927.10502953`；Newcombe, 1998, DOI `10.1002/(SICI)1097-0258(19980430)17:8<873::AID-SIM779>3.0.CO;2-I`。本工具实现独立比例差方法10、不作连续性校正；不支持顺序检验、多重比较、聚类用户、贝叶斯平台结果或收益统计。
