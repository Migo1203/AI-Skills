# Multi-Angle Set｜产品多角度套图使用说明

更新：2026-10-30。基于 [multi-angle-set 上游原文](../已知技能/源文件/xianyu110--ecommerce-image-skills/skills/multi-angle-set/SKILL.md)整理；固定版本、许可和归档范围见[来源说明](../已知技能/源文件/xianyu110--ecommerce-image-skills/来源.md)。

## 它能做什么

这个技能用于把同一件产品的参考图整理成一组不同角度的商品图。它先写明不能改变的产品特征，再统一背景、光线、构图和色调，为正面、侧面、背面、45°、俯视或细节等角度分别组织提示词，并在生成后核对结果。默认镜头清单是6张，可按实际需要调整数量。

它是**生图工作流与提示词方法**，不是三维扫描或精确建模工具。生成模型仍可能改变机身比例、网孔、按键、标识或未拍到的结构；技能没有证明能够完全消除产品形变。正面图无法证明背面和底面的真实样子，缺少的结构应补参考或标注未知。

## 使用前准备

1. **产品参考图**：尽量使用清楚的真实正面、侧面、背面、顶部和细节照片；每张参考图提供什么信息要说明白。已经通过的生成图可辅助对照画面，但产品结构以真实资料为准。
2. **不可改变的特征**：机身轮廓、宽高和厚度、颜色与材质、按键、接口、网罩、标识及位置。只写照片能证实的内容；不清楚的参数留空。
3. **画面要求**：需要哪几个角度、每张还是拼图、画幅、背景、光向、色温与是否留阴影。已选好的图片和不需要的元素也要写清楚。
4. **可用工具**：真正生成图片需要支持参考图的图像工具。当前聊天有图片生成工具，可在用户要求实际生成时使用；该工具没有向本记录返回具体模型版本。

## 实际操作步骤

1. **确认基准**：查看所有真实参考图，写出产品身份约束，包括外形、颜色、零件、标志与明确禁止出现的内容。
2. **选择角度**：列出实际需要的正面、侧面、背面、45°、俯视或细节图。优先从一张尚缺的角度试起，已经满意的图保留。
3. **统一画面**：给每张重复同一组背景、光向、色温、画幅和构图要求；物体在不同角度应保持合理透视，不能为了屏幕比例强行拉伸。
4. **生成与检查**：将身份约束、画面要求和参考图一起交给图像工具，逐张检查轮廓、机身厚度、网孔、按键和接口。只重做不合格的角度。
5. **交付和排版**：保留原图、参考来源及可用的输出文件；最终文字和排版可在 PS 中继续完成。上游的默认尺寸、平台数量和模型名称是作者的工作流建议，使用前需根据目标平台和当前工具实际情况核对。

## 小度音箱最小练习

已有可用的正面、45°和侧面选图；侧面的冷白修色版本仍需用户确认。若以后要测试尚缺的背面，可以直接发：

> 请读取已知技能中的 `multi-angle-set`，参考小度音箱的 N10 正面、N01 侧面实拍、N02 顶部实拍和 N04 背面实拍，先只生成一张白底背面候选图。保持真实机身的宽高比例、厚度、圆角、接缝与背面接口位置；只画参考图能确认的结构，不要编造细节。整张画面使用冷白色机身、纯白背景和柔和棚拍光，不要蓝色亮点、文字或额外装饰。保留之前选定的三张图。生成后对照实拍说明仍不能确认的细节。

**预期输出**：一张独立的正方形背面候选图，以及针对机身比例、接口和颜色的简短核对说明；若实拍看不清，应明确标记，不能称作实物完全还原。这个练习只是示例，本次未执行。

**不适用的请求**：只提供正面图，却要求准确重建背面的所有接口和底部结构。没有对应照片或产品模型时，技能无法知道这些真实细节。
