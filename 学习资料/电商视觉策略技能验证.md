# 电商视觉策略技能验证与使用

历史实战验证日期：2026-10-26，版本v0.1.0；布局更新检查日期：2026-11-06，版本v0.2.0。对象：[ecommerce-visual-strategy](../plugins/skill-lab/skills/ecommerce-visual-strategy/SKILL.md)。

这是一份独立的新技能：结合原视觉规划技能的信息层级、排版与审稿方法，以及视觉文案技能的产品分析、购买理由、图组任务与提示词方法，按 Migo 的制作流程重组。AI交付分析、策略、文案、提示词和PS建议；用户自行制作或选择素材、完成PS排版。两份原技能均保留，未覆盖。

- 使用本仓库已安装的 OpenAI Codex `skill-creator` 初始化，生成 `SKILL.md`、`agents/openai.yaml` 和所需的 `references/`。没有增加执行生图的脚本或服务依赖。
- `quick_validate.py` 检查通过；名称、描述、版本元数据和UI元数据可解析。默认提示词包含 `$ecommerce-visual-strategy`，未关闭默认自动选择策略。
- 两份参考文件分别用于按任务交付和编写画面提示词，入口已给出读取时机；执行新技能不需要同时安装两份原技能。
- 核对第三方MIT许可与来源版本，许可原文随新技能保存。两份原始 `SKILL.md` 的SHA-256与创建前一致：

## 真实任务检查

独立代理分别收到技能、具体请求和必要原始材料，未提供期望答案。输出写入临时目录，由主线程读取结果并对照实际材料复核；没有运行生图、修改图片或操作用户PSD。以下记录关注实际决策，不以标题或固定措辞匹配作为通过依据。
