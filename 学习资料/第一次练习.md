## 对电商视觉技能的拆解

| 项目 | 实际内容 |
| --- | --- |
| 用途 | 规划、审稿、统一电商图片和作品集项目的视觉 |
| 输入 | 原图、产品事实、尺寸、用途、受众及已有品牌要求 |
| 执行 | 识别任务 → 核对图片与事实 → 确定主信息 → 提出版式 → 检查亲密性、对齐、重复、对比及可读性 → 根据反馈修正 |
| 输出 | 规划时给版式参数与执行步骤；审稿时优先给最多三个“位置 → 原则 → 修改动作 → 预期效果” |
| 依赖 | 需要实际可读的图片和产品资料；使用生成工具或查询平台规范时，以当时实际可用的工具为准 |

## 用已有音箱项目做一个小练习

提示词：

```text
使用电商视觉技能，检查我1024×1536的居家海报。
底部说明与铅笔笔尖重叠，近景放大裁切是我有意选择的，请保留。
最多给三个修改动作，说明位置、理由和调整后的预期效果。
```

本次按流程得到的建议：

1. 底部说明开头与笔尖重叠，文字辨认受到干扰。将整行先上移约60px试排、保持居中，再检查与笔尖及产品阴影的间距。
2. 保留用户明确选择的近景构图，不要求恢复远景，也不要求重新生成已有合格背景。
3. 无字底图沿用v03；首次PS文字排版为v01，下次文字修改为v02，分别记录制作阶段。

这条建议的验证重点是“具体、能执行、尊重当前设计决定”，不是只说“优化排版”。60px来自当前海报的检查建议，不是所有海报都应套用的固定规则。

反例：“删除GitHub仓库中的重复文件”属于文件管理，不需要强行套用电商审稿技能。
