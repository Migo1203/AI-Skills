## 归档标记约定

- 来源性质与用途分开记录：自建、融合改编、原有导出、第三方原版分别标明，再填写学习辅助、电商视觉等用途。
- 每项链接到唯一维护源及来源说明；融合改编保留上游版本、署名与许可，第三方原版不标成个人原创。
- 版本与验证范围按实际记录填写；“已归档”“已安装或注册”“已验证效果”分别记录。没有单独版本号时以Git提交追踪，不补造版本。

本轮只整理归档标记，没有修改技能指令、名称或安装状态。
